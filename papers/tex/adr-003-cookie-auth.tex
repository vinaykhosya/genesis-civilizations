\subsection*{Context}
The admin dashboard \textbackslash{}texttt{/command} requires authorization for Vinay Khosya.

\subsection*{Decision}

\subsection*{Consequences}
Zero third-party identity provider dependency, instant setup, and zero local DB overhead.
