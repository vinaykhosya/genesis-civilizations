\section*{ADR-002: Require \textbackslash{}texttt{world.png} in Experiment Exports}

\subsection*{Status}
Approved

\subsection*{Context}
Visualizing world maps requires rendering 2D elevation, biome, and river layers.

\subsection*{Decision}
Require the simulation to save and export \textbackslash{}texttt{world.png} directly into the ZIP archive. We will not run serverless Python instances to re-render the world on the fly.

\subsection*{Consequences}
Minimizes backend cold starts, simplifies upload validation, and guarantees instant image load times on client devices.
