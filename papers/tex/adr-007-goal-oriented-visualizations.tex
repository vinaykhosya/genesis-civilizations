\section*{ADR-007: Goal-Oriented Visualizations (Laboratory Instruments)}

\subsection*{Context}
Adding standard charts for every variable (e.g. food levels, water indexes, spatial grids) can dilute research focus and introduce cognitive noise. Without intent-focused structure, charts fail to help the researcher draw conclusions.

\subsection*{Decision}
We establish a rule: \textbackslash{}textbf{Every visualization must answer a research question.}
\begin{itemize}
  \item No visualization should be added simply because the telemetry holds the data.
  \item Every chart in the Observatory (Evidence Explorer) must correspond to a clear scientific question (e.g. "Did scarcity reduce survival?", "Did cooperation emerge?").
  \item Visualizations must be designed as "Laboratory Instruments" (Microscope, Relationship Network, Genome Browser) mapped to specific observations.
\end{itemize}

\subsection*{Consequences}
\begin{itemize}
  \item Every visual indicator helps researchers validate or refute hypotheses.
  \item Reduces rendering performance bottlenecks by pruning unnecessary plots.
  \item Reinforces the scientific rigor and identity of the portal.
\end{itemize}
