\section*{ADR-005: Version-Controlled Experiment Schema}

\subsection*{Status}
Approved

\subsection*{Context}
The simulator schema will evolve as new genes, drives, or environmental layers are introduced.

\subsection*{Decision}
Enforce schema version metadata fields (\textbackslash{}texttt{schema\textbackslash{}\_version}, \textbackslash{}texttt{engine\textbackslash{}\_version}, \textbackslash{}texttt{export\textbackslash{}\_version}) in the root of \textbackslash{}texttt{config.json} and \textbackslash{}texttt{summary.json}.

\subsection*{Consequences}
The portal can dynamically inspect the \textbackslash{}texttt{schema\textbackslash{}\_version} of uploaded ZIPs and render legacy runs correctly using conditional data parsers.
